# Round 88：公开多源预训练后 R1/R2 七成员微调对照

## 合规范围

实验全部在 zzai 远程目录 `/root/projects/t2_public_pretrain_r1r2_20260816/` 完成。本轮只使用公开 STEAD、公开 INSTANCE-train，以及允许用于训练的 R1/R2 训练缓存。R1、R2 各 140 条训练样本，分别保留各 60 条独立 holdout；08 数据、08-an、08-exam 及其衍生物均未读取。本地未训练、未下载数据集。

## 预注册协议

比较两组相同结构的 7 成员模型：`scratch` 从随机初始化开始；`pretrained` 先在公开 STEAD（事件级 85% 子集）与 INSTANCE official train 上训练，再将编码器和回归头初始化到 R1/R2 多任务微调。微调固定 40 epoch、AdamW；R1 loss 权重 1.75，Round 58 的中心和斜率校准固定为 R1 `(4.30, 0.85)`、R2 `(5.20, 0.50)`。holdout 只在全部训练结束后一次读取。

## 结果

| 模型 | R1 校准分 | R2 校准分 | 均值 | R1 rho | R2 rho |
|---|---:|---:|---:|---:|---:|
| scratch | 135.3890 | 147.9562 | 141.6726 | 0.4427 | 0.4207 |
| 公开预训练后微调 | 135.1748 | 147.6216 | 141.3982 | 0.4342 | 0.3500 |

公开预训练初始化相对 scratch 下降 `-0.2744`，R2 下降更明显，说明在当前小样本、标签尺度和仪器分布下存在负迁移。该路线否决，不进入比赛候选；Round 58 的历史正式候选保持冻结。

## 论文检索与精读

通过 arXiv API 获得 50 篇去重记录，保存于远程 `papers.json`。精读至少 15 篇，主题包括地震震级估计、STEAD/INSTANCE、SeisBench、跨仪器域适配、负迁移、参数高效微调、知识蒸馏、深度集成、不确定性与校准。共同启示：预训练只有在标签定义、采样和仪器响应相近时才稳定增益；小样本微调更适合冻结大部分表征、分层学习率和事件级交叉验证；跨域初始化必须用独立目标域验证证明，不能仅凭源域 loss 或公开数据分数选择。
