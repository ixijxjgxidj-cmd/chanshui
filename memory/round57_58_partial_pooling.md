# Round 57-58：部分池化中心校准与预注册验证

日期：2026-08-16

## Round 57 文献与方法

检索 18 个主题得到 117 篇候选，精读跨域校准、域漂移不确定性、域专属 BatchNorm、多源域适配和 test-time adaptation 论文。关键原则：跨域偏移应使用保守的部分池化，而不是极端单域重加权；中心先验可以来自训练侧已知标签，预测批次本身只提供无标签中心。

Round 56 的七成员 OOF 预测上测试了：

`q = (1-alpha)*c_pred + alpha*c_train + slope*(p-c_pred)`

其中 `c_pred` 是当前预测批次中位数，`c_train` 是训练侧轮次中位数。严格 5 折中，`alpha=.25`、R1 slope=.85、R2 slope=.50 的均值为 **142.88**，超过冻结 42c 参考线 140.76；该值由每折训练标签估计中心，未使用折内验证标签，故预注册进入一次 holdout 验证。

## Round 58：一次性预注册 holdout 验证

配置在读取 holdout 前固定：

- 多任务预训练 B（震级+距离+深度）
- R1 loss 权重 1.75，R2 权重 1.0
- 7 个全量成员
- R1 `alpha=.25, slope=.85`
- R2 `alpha=.25, slope=.50`

训练只用 R1/R2 train；holdout 标签只在最终评分段读取。此次是累计第 8 次 holdout 读取，之后不得再用 holdout 选择或调参。

| 轮次 | raw MAE | raw score | 校准 MAE | 校准 score | raw bias | 校准 bias | r |
|---|---:|---:|---:|---:|---:|---:|---:|
| R1 | .2853 | 143.30 | **.2779** | **144.42** | +.115 | +.059 | .737 |
| R2 | .3104 | 137.93 | **.2292** | **154.16** | -.130 | -.101 | .630 |
| **均值** | | 140.61 | | **149.29** | | | |

相对 42c 冻结基线（140.76）提升 **+8.53 分**。R2 的系统性低估得到显著缓解，R1 也有小幅改善。该结果证明“多任务预训练 + R1/R2 平衡微调 + 部分池化中心校准”是当前最强候选。
