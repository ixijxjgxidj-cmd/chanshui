# Round 64：无标签映射的批量大小敏感性

日期：2026-08-16

在训练侧 5 个随机折分中模拟目标批次大小 20、40、60、100、140，使用 Round 63 的 bootstrap 中位数映射和 alpha=.75：

| 批量大小 | 平均得分 | 5 折范围 |
|---:|---:|---:|
| 20 | 146.80 | 146.39–147.34 |
| 40 | 146.99 | 146.47–147.25 |
| 60 | 147.07 | 146.36–147.71 |
| 100 | 146.83 | 146.37–147.31 |
| 140 | 147.13 | 146.69–147.60 |

结论：无标签映射对批量大小不敏感，20 个以上样本即可稳定估计中心；部署时优先使用全批次中位数，内存受限时使用至少 20 个样本的滑动批次。该结论只来自训练侧模拟，不涉及 holdout 或 08 标签。
