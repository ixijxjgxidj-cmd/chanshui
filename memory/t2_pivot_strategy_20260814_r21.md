# T2 战略转向总结（2026-08-14 轮21）

## 一、核心发现（已实验证实）

### 1. 现役 T2 模型负技能 -40 分

- **现役**：SeismicXM-1024维 + Ridge(α=30)，08 得分 **95.4**（MAE 0.523）
- **最优常数**（c=4.2，5折CV诚实评估）：得分 **135.4**
- **差距**：-40 分 ≈ -30% relative
- **冠军**：159.28（MAE ~0.204）
- **技能分解**：冠军 vs 常数 = +24 分（真技能），我们 vs 常数 = -40 分（负技能）

### 2. R1 数据集物理关系已破坏

| 观测 | 数值 | 结论 |
|---|---|---|
| 振幅动态范围 | 3.91 decades（10²~10⁵） | 正常 |
| 震级范围 | 2.1 级（4.0~6.1） | 正常 |
| log(Amax) vs mag | r = +0.009 (p=0.90) | **零相关**，物理上不可能 |
| npts vs mag | r = -0.41 (p<1e-9) | **强泄漏**（小震长、大震短）|
| 3~10Hz能量比 vs mag | r = -0.21 (p=0.003) | **反向**（大震高频强）|
| Ridge(频谱20维) vs 中位数常数 | 技能 -0.007 | 无信息增量 |

**诊断**：波形已被逐文件缩放，绝对振幅信息销毁；震级与 npts（文件长度）的负相关说明标注或截取存在系统偏差；频谱关系反向违反 Brune 源模型。R1 不适合作为震级估计的技术验证场。

### 3. 归一化销毁振幅（代码已确认）

`src/phasepicker/tasks/seismicxm_features.py` 第52-53行：

```python
out -= out.mean()
out /= (np.abs(out).max() + 1e-6)  # 逐道归一化
```

SeismicXM 预训练任务是**事件分类**（不是震级），预训练时归一化无害，但下游 T2 用它做震级回归时**只能依赖形状特征**（频率、持续时间），而非振幅。结果是 1024 维模型拟合 200 样本时严重过拟合到 npts 泄漏和噪声。

### 中期（4~10 轮）：STEAD/INSTANCE 震级模型

**为什么换数据集**：
- STEAD 110万地震，包含 `source_magnitude`（通常是 M_L 或 M_w）
- INSTANCE 127万地震，震级范围 -2~8
- 波形**未归一化**（raw counts），仪器响应已去除
- 震中距、深度标注完整，可构建物理约束 `M = f(A, Δ, h, freq)`

**方法**：
1. 双分支架构：振幅分支（log Amax、log RMS、Pd）+ 形状分支（频谱质心、带比、持续时间）
2. 距离代理：S-P 时差、或用我们 T1 拾取器直接提供
3. 损失函数：直接优化截断评分 `max(0, 1-|Δm|)`（Huber 或自定义）
4. 目标：在 STEAD 测试集上 MAE < 0.3（折算 >140 分），迁移到 08 保守估计 >120 分（仍比现役 +25）

### 长期（10+ 轮）：MagNet 复现或微调

MagNet（2021，Science Advances）是单台站深度震级 SOTA，STEAD 上 MAE 0.20~0.23。冠军 0.204 可能就是这个方向。需要：
- 1D CNN 或 Transformer（输入**未归一化**波形）
- 多任务：震级 + 距离 + 深度联合预测（物理一致性约束）
- 训练集 >10 万样本（STEAD 够）
