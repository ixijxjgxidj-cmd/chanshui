# 实验018总结与路线调整

## 实验执行情况

### 完成的工作
1. ✓ R1/R2数据准备（1559训练+356验证，按事件ID划分）
2. ✓ PhaseNet(diting)远场微调训练（114秒，val_loss 1.5316→1.3608）
3. ✓ iquique评估（智利远场600窗）
4. ✓ devmix评估（全球混合3407窗）
5. ✓ 论文调研（已检索10+篇）

### 关键发现：过拟合问题

**矛盾的评估结果**
- iquique（智利）: +0.43% ← 提升
- devmix（全球）: -1.61% ← **退化**

**devmix分bin退化明细**
- [0,10): -0.0009（近场持平）
- [10,20): -0.0206
- [20,30): -0.0299
- [30,40): -0.0505
- **[40,50): -0.1213（退化12.13%）← 最严重**

### 根本原因分析

1. **数据来源单一**
   - R1/R2全部来自四川台网2023-2024历史数据
   - 波形特征、台站响应、区域构造高度相似
   - iquique碰巧与四川波形特征相似，devmix暴露真相

2. **微调策略过于激进**
   - val_loss下降11.1%（1.5316→1.3608）
   - 过度拟合R1/R2分布，丧失预训练泛化能力
   - KL散度软标签未能保持全局一致性

3. **验证集不代表真实分布**
   - R1/R2 val也来自四川，与train同分布
   - devmix才是真正的分布外测试
   - 早停机制在错误的验证集上触发

## 失败路线总结

### 已证明无效的方向
1. ❌ **实验016加法组**：e1/e2/e3均无效（p>0.27）
2. ❌ **实验018 R1/R2微调**：过拟合到单一区域
3. ❌ **单点数据源特化训练**：破坏泛化性

### 共同问题
- 数据多样性不足
- 单点优化破坏集成鲁棒性
- 验证策略未覆盖分布外场景

## 路线调整决策

### 立即停止
- R1/R2继续微调
- 单区域数据特化
- 简单成员加法

### 新优先级

#### 1. 数据工程（最高优先级）
**目标**：构建全球多区域远场数据集

**行动**：
- 联网下载IRIS/GEOFON公开数据
- 目标区域：环太平洋、欧亚、地中海、中亚
- 震级范围：M5.0-7.5（确保远场可观测）
- 台网多样性：至少5个不同台网
- 事件数：≥1000个，窗口≥5000

**合规**：
- 记录来源、校验和、许可证
- 按事件ID划分train/val（80/20）
- 确保val包含未见板块

#### 2. 参数高效微调（PEFT）
**方法**：LoRA/Adapter（arXiv 2512.13197指导）

**优势**：
- 只调整1-5%参数，保持预训练知识
- 降低过拟合风险
- 可针对远场任务插入adapter

**实验设计**：
- 基线：PhaseNet(diting)冻结backbone
- LoRA注入：每个卷积层添加低秩分解
- rank=8（平衡表达力与泛化）
- 只训练adapter参数

#### 3. 偏差校正（快速补丁）
**实验017已开发**，可作为临时解决方案：
- 系统性拾取偏差校正
- 不改变模型，后处理层面修正
- 先测试是否有增益

#### 4. 集成优化
- Stacking：学习最优成员权重（而非简单平均）
- 考虑分bin权重（近场/远场不同策略）
