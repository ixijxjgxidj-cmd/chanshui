# Round 79：公开数据 JEPA 跨域评分修订

## 合规范围

- 训练与网络数据获取只在 zzai 远程机进行。
- 本轮只读取公开 STEAD 与公开 INSTANCE 缓存；运行时 `compliance_guard` 对比赛波形路径返回 `GUARD_BLOCKED`。
- 未读取 08、R1、R2，也未使用其标签、特征、预测、holdout 或任何衍生物进行训练、调参或选择。
- 实验目录：`/root/projects/t2_jepa_crossdomain_fix_20260816/`。

## 根因修订

旧版 `train39b_jepa.py` 的校准斜率网格从 0 开始。跨域排序失效时，`lambda=0` 会把预测变成常数，从而使 hinge 分数虚假达到 200，掩盖真实跨域能力。修订版将网格固定为 `0.05..1.50`，并同时报告未校准相关性与固定斜率分数。该修订只影响公开基准，不触碰比赛数据。

## 数据与协议

- STEAD：60,466 条 P-5s..P+5s、100 Hz、三分量波形；SHA-256 `d3056121b14a186b9fbbcef5b09627a718427f5958c77a2d3391ac5bde34cf45`。
- INSTANCE：21,209 条公开 train/dev 波形；SHA-256 `fff43e52dc9bdd7179264855c4120cd54463206fcd913d26025910c43e4b27fa`。
- STEAD→INSTANCE：按 source/event 分组，STEAD 训练与标定事件互斥，INSTANCE dev 只评估一次。
- 对照：同一编码器/微调预算的监督 scratch 与 RMS-normalized JEPA 预训练。
- 选择：不使用目标 INSTANCE dev 选择参数；跨域斜率固定下限为 0.05。

## 结果

| 臂 | INSTANCE 未校准 rho | 固定评分 |
|---|---:|---:|
| scratch | 0.0084 | 198.58 (`lambda=0.05`) |
| JEPA | 0.1023 | 198.84 (`lambda=0.05`) |

JEPA 的排序相关性提高约 0.094，固定斜率分数提高 0.26。提升很小，只证明公开跨域表征存在弱正信号；没有任何比赛模型升级或生产选择。

旧结果中“校准 200 分”不再引用为有效证据，因为其最佳 `lambda=0` 是常数退化。旧文件保留为历史审计，但本轮以新协议结果为准。
