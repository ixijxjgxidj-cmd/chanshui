# Round 52：多任务预训练（震级 + 震中距 + 深度）

日期：2026-08-16

## 动机与文献依据

Round 51 否决了全部后处理校准路线，剩余唯一杠杆是降低基模型残差 `s≈0.292`。基模型相关系数是天花板：OOF r=0.60-0.64，holdout r=0.72，对应残差 0.45×√(1−0.72²)≈0.31，与实测吻合。

本轮检索 599 篇，精读 18 篇。三条直接相关的结论：

1. **2101.02010（Münchmeyer 等，transformer EEW）**：基础模型系统性低估大震级事件，可通过跨区域迁移学习缓解；该失效模式对多数深度学习 EEW 模型普遍存在，根因是黑箱建模。对应 Round 45 诊断的「对 R2 系统性低估 0.224 级」。
2. **2408.06629（FisH）**：统一 phase picking + location + magnitude，震级误差 0.14，P 后 3 秒 0.18。
3. **2310.01037（SeisT）**：多任务基础模型，震级估计相对提升 8.0%，同时输出震中距与后方位角。

物理机制：单台站振幅 ≈ f(震级, 距离, 衰减)。仅监督震级时网络需隐式解耦距离；显式监督距离可强制解耦。R1/R2 无距离标签，但 `outputs/t2_cache_p10` 的 aux 提供 `[log10(dist+1), depth, log10(noise_rms), snr_db, noise_len_s]`，68872 条，输入 (3,1000) 即 P±5s，与 R1/R2 窗口同构，距离与深度标签 100% 有效。

## 预训练阶段结果（不可用于裁定）

同种子、同架构、同调度，唯一差异是辅助头与辅助损失。STEAD p10 事件级分组划分，train 58994 / val 9878。

| 变体 | M4-6.1 MAE | score | r |
|---|---:|---:|---:|
| A_single（第一次） | 0.3682 | 127.88 | +0.4032 |
| B_mtl（λ_d=0.3, λ_z=0.1） | 0.3835 | 124.93 | +0.3791 |
| A_single（第二次，同种子） | 0.4135 | 119.47 | +0.3865 |
| B_mtl_low（λ_d=0.03, λ_z=0.01） | 0.3090 | 139.07 | +0.3674 |

**这些数字不能作为裁定依据。** `A_single` 在完全相同的种子下两次跑出 0.3682 与 0.4135，逐 epoch 在 0.31~0.56 间跳动，「最佳 epoch」是在拟合验证噪声。多任务在预训练域上 MAE 与 r 的方向还相互矛盾（B_mtl_low 的 MAE 最好但 r 最差）。

## 裁定协议（Round 52b，进行中）

四个变体在下游 R1/R2 上同协议微调，唯一差异是初始权重：`scratch`（随机初始化，对照下界）、`A_single`、`B_mtl`、`B_mtl_low`。

微调超参对齐 42c：lr=2e-4，wd=1e-3，40 epoch，bs=32，gain aug，拉普拉斯异方差损失。R1/R2 各自 5 折 round-aware CV，每折 3 个种子平均以压制种子噪声，同时报告单种子散度的标准误，用于判断变体差异是否超过噪声。两种口径：raw score200 与 FT-center+slope。

合规：预训练只用 STEAD 衍生的 p10 缓存；下游只用 R1/R2 预注册 train 侧；未读 holdout（累计仍为 7 次），未接触 08。
