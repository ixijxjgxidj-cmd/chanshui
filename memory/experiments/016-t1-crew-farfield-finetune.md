## 1. 为什么换数据源，而不是继续在旧池上采样

实验 015 原计划对旧池（ETHZ+CREW chunk000）的远场窗做 ×2/×4 上采样。本轮实测否证了这条路的
上限：**ETHZ 本身几乎没有远场样本**。

| 数据集 | 双标注道 | S-P 中位 | >=10s | >=20s | >=40s | max |
|---|---:|---:|---:|---:|---:|---:|
| ETHZ（前 20000 行） | 9803 | 4.52s | 7.06% | 0.06% | ~0 | 24.1s |
| GEOFON | 2791 (1.0%) | 19.9s | 88.00% | 49.23% | 14.01% | 361.3s |
| **CREW 000-004** | **27999** | **34.7s** | **100%** | **80.05%** | **41.34%** | 201.5s |

对只有 7% 远场样本的池做 ×4 上采样，等于把同一小批窗重复四遍，只会过拟合那几百条；
换成 CREW 才是真正补足分布。**这是对实验 015 方案的修正，理由是新的实测证据。**

## 2. 窗长约束下的可用性（重要边界）

池窗长 3001 点 @50Hz = 60.02s，首尾各留 250 点（5s）盲区，因此 P 与 S 同窗要求
`S-P <= (3001-500)/50 = 50.02s`。CREW 有 5548 条（19.8%）S-P>50s，**本实验直接丢弃**，
不做"只保一个相位"的半标注窗——那会引入假阴性标签。

实测各分箱（CREW 000-004，S-P<=50s 共 22451）：

| S-P | 窗数 |
|---|---:|
| [10,15) | 1784 |
| [15,20) | 6141 |
| [20,25) | 4244 |
| [25,30) | 3068 |
| [30,35) | 2252 |
| [35,40) | 1769 |
| [40,45) | 1650 |
| [45,50) | 1534 |

覆盖了实验 015 诊断出的粗大错时窗 S-P 中位 26.10s（p10/p90 = 10.68/37.30）整个区间。

## 3. 双机分工（本轮新增的工程结论）

单机走不通：zzai 容器出网只有 1.07 MB/s 单流 / 1.64 MB/s 六并发，CREW 五块原始波形
约 25 GB，全下要 4h+。而 tor1（多伦多）到 DESY 单流 9.36 MB/s、四并发 20 MB/s。

因此：**tor1 做数据前置站**（下载 + 抽窗 + 丢弃原始波形），**zzai 只做训练**。
抽窗后池体积约为原始的 2%（22451 窗 gzip 后约 1 GB），过隧道成本可接受。
`scripts/crew_farfield_pool.py` 逐 bucket 流式处理，适配 tor1 的 2GB 内存。

## 4. 三臂设计（单变量）

| 臂 | 训练池 | 说明 |
|---|---|---|
| A0（对照） | 实验 014 臂 A 权重，不重训 | 已有 dev 数字可直接引用 |
| F1 | 近场池 + CREW 远场窗（1:1 目标配比） | 温和补远场 |
| F2 | 近场池 + CREW 远场窗（远场占比 ~50%） | 检验是否单调 |

除池的 S-P 分箱构成外，起点权重（`guangxi_sd.pt`）、`--pretrained diting`、epochs、
batch、lr、seed、sigma 全部与实验 014 臂 A 一致。

## 5. 判定顺序

1. 主指标：远场分箱粗大错时率是否下降（这是官方判零的直接来源）。
2. 护栏：近场分箱均分不得退化 >0.005（防"拆东墙补西墙"）。
3. F1/F2 单调则取更优；非单调则取远场改善且近场不退化者。
4. 通过后才做集成级评估；R1/R2 只作不回归检查并同报四口径。

## 6. 已知风险（如实记录）

- **域差异**：CREW 是全球台网（IU/II/BK 等宽频带），与广西区域台网的仪器和噪声特性
  不同。远场增益可能部分被域偏移抵消，需在 dev 上按 S-P 分箱分别看，而不是只看总均分。
- **深源事件**：CREW `source_depth_km` 中位 29.5km、p90 160km、max 690.7km，深源比例
  明显高于区域浅震。深源波形的 P 初动更陡，可能引入与赛区不符的先验。
- 这两条都无法靠 R1/R2 验证（合规禁止用它们选参），只能靠公开 dev 分箱 + 跨区域最坏
  表现来判断，并如实报告不确定性。
