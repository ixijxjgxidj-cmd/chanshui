# 实验016总结与下一步方向

## 关键结论
1. **远场微调轴到头**：F1(61%远场)在单模型最优(1.6745)，但集成c3(1.5646)远超任何单模型
2. **替换策略失败**：d1(替换两个)显著退化-0.0166，d2(替换一个)退化-0.005
3. **加法策略无效**：e1(c3+F1)、e2(c3+F1+F4)、e3(c3+F3)全部退化0.004-0.005(不显著但无提升)
4. **S波是瓶颈**：S gross=9.0%(P只有3.0%)，mean_abs=0.499s(接近2s上限)，SP>30s时S gross率达20-24%

## 下一步三条路径（按推荐优先级）

### 路径A：S波专项提升（推荐，针对性最强）
**依据**：2511.06731论文指出S波幅度抑制问题，用对抗形状学习可解决
**方案**：
1. 诊断当前c3集成的S波预测分布：是否存在幅度抑制（高SNR但低于阈值）
2. 若存在，实施对抗训练增强S波峰值响应
3. 针对SP>30s远场事件单独微调S波head
4. 实验池：用judge_pnw_near(近场护栏)和geofon_sp10_50(远场)双验证

**预期收益**：S gross从9%降至6%可使总分从1.5646提升至~1.62

### 路径B：模型蒸馏（用户原始目标之一）
**依据**：c3七成员集成已达1.5646，蒸馏可压缩为单模型同时保持性能
**方案**：
1. 用c3的soft logits作为teacher，蒸馏成单个学生模型
2. 温度T=3-5，loss = alpha*KL(student||teacher) + (1-alpha)*CE(student,hard_labels)
3. 学生架构同guangxi_sd.pt，从头训练或从guangxi初始化
4. 在dev_mixed + iquique + geofon三池联合验证

**预期收益**：单模型达到c3的90-95%性能(~1.50)，推理速度提升7倍

### 路径C：JEPA架构重构（用户原始目标，长期方向）
**依据**：自监督预训练可学习更好的地震波形表征，但需要大量无标注数据
**方案**：
1. 文献调研：JEPA在时序信号上的应用（≥5篇论文）
2. 收集公开地震波形数据集（STEAD/INSTANCE/DiTing等）
3. JEPA预训练：masked prediction而非reconstruction
4. 在预训练backbone上微调P/S head

**预期收益**：泛化性更强，但周期长(1-2周)，优先级低于A/B
