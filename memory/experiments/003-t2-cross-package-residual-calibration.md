## 1. 本轮目标

检验以下可证伪问题：

> 只使用训练源包的交叉拟合预测和 OOF residual，在“基线预测值 + 极低维 PCA”邻域内做强收缩残差修正，能否在不接触目标标签、目标均值或目标批次统计的条件下，同时降低 R1→R2 与 R2→R1 的 MAE 和有符号偏差？

本轮不是端到端重训，不调用新的 SeismicXM 编码器，不改变 T1/T3，也不重复历史失败的 quantile/Huber/双模型平均。

## 3. 假设

### 主假设

虽然源包 OOF 总体 signed bias 接近 0，但 residual 可能随基线预测值和少数低维表征方向呈现稳定的回归收缩结构。交叉拟合 residual 能避免用训练内残差制造虚假可预测性；强收缩局部估计可能修正一部分跨包偏差，而不需要目标批次。

### 反假设

跨包偏差主要是标签先验/条件分布变化、绝对振幅信息丢失或源/目标整体截距变化。此时 source-only OOF residual 不包含目标偏移方向；局部校准只能在包内看似改善，跨包无效或反向恶化。

## 5. 候选机制与固定网格

### 5.1 源包 OOF residual

在每个训练源包内部使用 `5` 折、shuffle、固定随机种子生成 OOF 预测：

```text
residual_i = y_i - ridge_oof_prediction_i
```

每个样本的 OOF 预测必须来自没有见过该样本标签的 Ridge。

### 5.2 低维校准空间

校准空间由两部分组成：

1. 源包 OOF 基线预测值（始终存在）；
2. 源包特征经 `StandardScaler + PCA(whiten=True)` 得到的 `0/8/16` 个分量。

最终拟合时，源样本使用 OOF 基线预测；目标样本使用“在完整源包拟合的 Ridge”预测。PCA、标准化器和预测值标准化参数均只在源包拟合。

为避免 `PCA=0` 时单一标量在 cosine 归一化后退化为正负两个点，所有校准向量固定附加一个常数 `1` 的齐次坐标。该坐标不含标签或目标信息、不参与网格，也不改变“预测值 + 0/8/16 个 PCA 分量”的可学习信息边界。

### 5.3 局部 residual 估计

- 校准向量最后做 L2 归一化；距离为 cosine distance。
- 邻居数 `k ∈ {20, 40}`。
- 权重固定为 `1 / (distance + 0.05)`。
- 局部 residual 为邻居 residual 的加权均值。
- 修正强度 `shrinkage ∈ {0.25, 0.50}`。
- 局部 residual 先截断到 `[-0.20, +0.20]`，再乘 shrinkage。
- 最终预测仍 clip 到 `[0.0, 9.9]`。

固定激活候选共 `3 × 2 × 2 = 12` 个；另有不修正的 Ridge 基线。实验后不得扩展 PCA 维数、k、shrinkage、截断幅度或距离权重网格。

### 5.4 源包距离闸门

对源残差库逐样本 leave-one-out，计算其 `k` 邻居平均 cosine distance；固定取源包分布的 `90%` 分位为阈值。目标单样本平均邻域距离高于该阈值时，回退到 Ridge 基线。

该闸门只控制候选覆盖率，不被描述为已证明的误差概率。输出必须报告：

- 阈值；
- 目标覆盖率；
- 覆盖内/外 MAE；
- 邻域距离与绝对误差的 Spearman 相关（仅诊断，不用于选型）。

## 6. 嵌套源包选择协议

对 R1、R2 分别独立执行 `5` 次重复 × `5` 折外层验证：

1. 外层训练折内再做 5 折交叉拟合，生成 residual 库。
2. 所有 scaler/PCA/距离阈值只在外层训练折拟合。
3. 外层验证折只用于产生未见预测。
4. 聚合 25 个外层折后，按 MAE 选择配置。

防止“微小噪声收益”规则：

- 若最优激活配置相对源包外层 Ridge 的 MAE 改善小于 `0.005`，该源包选择基线，不启用修正。
- 候选 MAE 相差不超过 `0.001` 时，按固定复杂度顺序选更简单者：PCA `0 < 8 < 16`，`k=40 < k=20`，shrinkage `0.25 < 0.50`。
- 不能用另一包的跨包标签改变本源包选择。

配置稳定性通过条件：

- R1 与 R2 都选择激活修正；
- 两者 shrinkage 相同；
- PCA 维数最多相差一个相邻档（允许 `0↔8` 或 `8↔16`，不允许 `0↔16`）；
- k 可在 `20/40` 间不同。

任一源包回退基线、shrinkage 不同或 PCA 选择跨两档，均记为“机制选择不稳定”，开发判定失败。

## 7. 双向开发验证与成功门槛

源包选型完成后：

- 用 R1 选出的配置在完整 R1 上拟合，预测 R2；
- 用 R2 选出的配置在完整 R2 上拟合，预测 R1；
- 跨包标签只用于最终评估，不用于配置、门控或参数拟合。

开发阶段必须同时满足：

1. R1→R2 MAE 相对 Ridge 改善至少 `0.010`；
2. R2→R1 MAE 相对 Ridge 改善至少 `0.010`；
3. 两方向平均 MAE 改善至少 `0.015`；
4. 两方向 `abs(signed bias)` 均严格下降；
5. 任一方向不得恶化；
6. 两个源包外层 OOF MAE 均不得相对 Ridge 恶化超过 `0.010`；
7. 配置稳定性通过；
8. 不增加编码器调用、TTA 次数或主要生产延迟。

只有全部满足，`development_pass=true`，才允许进入 08 一次性终检。任何单项失败都立即锁定 `terminal_08_allowed=false`。

## 8. 08 一次性终检协议

只有开发通过时执行：

1. 核对终检缓存 SHA-256；
2. 在 R1/R2 各自 12 个配置的源包 OOF 表上，选择“平均 OOF delta 最低”的共同配置；并列时沿用第 6 节复杂度顺序；
3. 在合并的 R1+R2 上重新生成 5 折 OOF residual 库并拟合该共同配置；
4. 对 08 预测一次，记录逐样本误差；
5. 不得根据 08 结果换配置、改截断、改 gate 或加常数。

08 采用门槛：

- MAE `≤ 0.513197455`，即相对冻结 `0.523197455` 至少改善 `0.010`；
- `abs(signed bias) ≤ 0.099781905`；
- 结果不是固定标签均值或固定包间偏移；
- 定向测试、全量测试与 bundle/API 回归全部通过。

08 未通过则整轮拒绝，不进入生产。

## 11. 已知历史负结果与“本轮为何不是重复”

不得原样重复：

- GBR quantile：R1→R2 `0.7464`、R2→R1 `0.7066`；
- Huber：`0.7164/0.7587`；
- QuantileRegressor：最高维小样本下退化；
- 双 Ridge 简单平均：08 `0.5509`；
- 相同绝对幅值/手工特征拼接：弱于 deep1024；
- 根据 08 `+0.09978` 直接减固定常数。

本轮实质不同之处：

1. residual 来自严格交叉拟合，不是训练内残差；
2. 修正是源包内部、低维、局部、强收缩，不替换 Ridge 主模型；
3. 每个方向的配置仅由其源包 OOF 选择；
4. 双向跨包是 08 之前的硬门槛；
5. 失败时不读取 08，避免终检反复调参。
