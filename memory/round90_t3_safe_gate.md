# Round 90：T3 生产头优先的 OOF 安全门控

## 合规范围

本轮在 zzai 远程目录 `/root/projects/t3_safe_gate_20260816/` 完成。输入只包括已生成的 R1/R2 SeismicXM 特征缓存；没有读取 08-an、08-exam 或任何 08 衍生物，也没有使用来源不明的五类标签。本地没有训练。

## 预注册门控协议

候选模型固定为 `StandardScaler → L2 Normalizer → cosine kNN(k=5)`，生产基线固定为 `L2 Normalizer → cosine kNN(k=5)`。先在 R1 上进行 5 折 OOF，使用候选置信度与基线置信度的分位点网格选择门控；生产模型始终为默认回退。选择约束为 OOF accuracy 不低于生产基线，平衡准确率优先，覆盖率越低越优先。所有门控参数锁定后，才读取 R2 做一次跨包检查。

## 结果

| 评估 | 生产基线 | 标准化候选 | OOF 门控 |
|---|---:|---:|---:|
| R1 OOF 正确数 | 180/200 | — | 181/200 |
| R1 OOF accuracy | 0.9000 | — | 0.9050 |
| R1 OOF balanced accuracy | 0.8642 | — | 0.8682 |
| R1→R2 正确数 | 187/189 | 188/189 | 188/189 |
| R1→R2 accuracy | 0.9894 | 0.9947 | 0.9947 |

最终门控阈值均为基线/候选置信度 `0.8`，R1 OOF 覆盖率 18%，R2 覆盖率 12.7%。门控保留了候选的单条跨包增益，没有引入相对生产头的回归；但只有一个 R2 包，不能据此声称普遍提升，也不进入 08 终检。

## 文献检索与精读

本轮通过 arXiv API 得到 50 篇去重记录，保存于 `papers.json`，并精读至少 15 篇，覆盖 selective classification、selective risk、置信度校准、域泛化、协变量偏移、地震分类和长尾分类。共同启示：选择性预测必须将覆盖率和风险同时报告；校准与门控统计量只能由训练/OOF 估计；跨域模型应保留强基线回退；单个目标包的提升不足以证明外部泛化。
