## 2026-08-11：不自动积分加速度

- 决策：保留输入原始物理量，不根据通道码自动执行加速度到速度积分。
- 证据：官方群确认“数据不限制加速度记录，以速度为主”；08 两个 HN 文件上的积分变体均劣于原始输入。
- 后续：若取得可靠仪器响应与单位元数据，可另立预注册实验，不在主链路做启发式转换。

## 2026-08-11：缺口屏蔽先量化、后上线

- 录取条件：合成缺口测试通过；无缺口预测逐位一致；四包或可用历史包最坏口径不退化；屏蔽窗宽有物理与模型感受野依据。

## 2026-08-11：T1 与 T2/T3 使用不同的短窗下限

- 决策：`/pick` 和任何依赖 picks 的估计器继续拒绝 `<5s`；`needs_picks=False` 的 T2/T3 固定窗模型允许任意正长度输入。
- 直接证据：第 1 轮官方 T3 有 6 个 1.5–3.5 秒第 5 类样本；旧 API 全部空响应，生产 SeismicXM 对六条均正确分类。
- 收益：第 1 轮有效 T3 accuracy 由旧 API 91.0% 恢复到 94.0%；第 5 类 recall 40%→100%。
- 安全边界：不是全局关闭时长检查；只有不依赖 PhaseNet picks、具备自身固定窗补齐的模型可绕过 5 秒下限。

## 2026-08-11：拒绝 T3 中心化/等类原型头，不消耗 08 终检

- 决策：保留生产 `Normalizer + cosine kNN(k=5)`；拒绝本轮训练折中心化、NCM/top-m/多原型及 R1 margin/support 门控，不构建 bundle、不部署。
- 证据：候选在第 1 轮嵌套验证的 balanced accuracy 从 `0.865636` 升至 `0.908364`，但第 1→2 轮从基线 `187/189` 崩至 `121/189`；门控覆盖第 2 轮 91.5%，仅恢复到 `130/189`。
- 解释：训练包均值中心化显著放大域移；即使移除中心化，对应 raw top-m 最好也只有 `182/189`，仍未达到预注册 `186/189`。包内 margin/support 不能当作跨包 OOD 检测器。
- 防泄漏边界：`development_pass=false` 后不提取、不查看 08 T3 特征；不得用第 2 或 08 标签事后挑一个 raw 配置再宣称通过本轮。
- 重开条件：出现实质不同的域不变机制、可靠无标签域移信号或新的独立验证包。

## 2026-08-11：拒绝 T2 source-only OOF residual 校准，不消耗 08 终检

- 决策：生产继续使用 `StandardScaler + Ridge(alpha=30)`；拒绝预测值/低维 PCA 邻域上的源包 OOF residual 强收缩校准，不构建 bundle、不改 API、不部署。
- 证据：R1/R2 源包重复嵌套 OOF 分别改善 `0.018247/0.008458 MAE`，且都选择 `pca0_k40_s50`；但 R1→R2 从 `0.621046` 恶化到 `0.621532`，R2→R1 从 `0.660726` 恶化到 `0.669618`，两个方向绝对 signed bias 均扩大。
- 解释：源包 residual 能学习同包回归收缩，却不包含目标包整体截距/条件分布漂移的方向；距离闸覆盖 `90–93%`，也没有形成可靠 OOD 风险信号。
- 防泄漏边界：`development_pass=false` 后没有计算终检缓存哈希、没有打开 08 T2 特征；不得用 08 或跨包标签事后改 PCA/k/shrinkage/gate 或加入固定包均值差。
- 重开条件：出现合法无标签目标批次、解释偏移的元数据、目标区/DiTing 标签或新的独立验证包。

## 2026-08-11：第 4 轮只测试长记录完整低可信 P/S 事件删除

- 决策：固定现有 5 成员长记录推理、`-1 dB` SNR 闸和 20 秒同相位去重；只在 `>300s` 后处理层测试 FIFO `0.2–60s` P→S 配对与几何联合 confidence 阈值 `{0.35,0.40,0.45}`。
- 理由：R2 两个长文件与 08 五个长文件分别集中约 `23.5%/39.4%` 的 T1 损失；多数额外拾取能组成完整假 P/S 对，事件联合 confidence AUC 约 `0.7616`，继续扩大固定 dedup 窗已有真实事件合并负结果。
- 防重复边界：短文件 P/S 联合重选在 R2/08 仅 `+0.0/+0.1`，本轮所有 `≤300s` 输出必须逐位不变；不得删除全部 orphan、重扫 `long_dedup_s` 或新增事后阈值。
- 录取：R2/08 各自源包选型、leave-one-file-out 稳定、双向跨包和较低 tau 共同候选必须同时通过；四种数量罚方向一致，逐文件不得新增 FN、降低 P/S 时差分或降低文件分数。
- 生产边界：当前只冻结研究与预注册，尚未运行阈值评分；只有正向结果、全量回归和可关闭开关完成后才允许部署。

## 2026-08-11：拒绝长记录 FIFO 事件 confidence 删除

- 决策：保留生产 20 秒同相位去重；拒绝 tau `0.35/0.40/0.45` 的 FIFO 完整 P/S 事件几何 confidence 删除，不增加生产开关、不改 API、不部署。
- 基线可信度：冻结缓存、答案和基线哈希匹配；OFF 路径 7 文件计数、逐文件残差/FP/FN/时差分/文件分及两包四种完整口径均在 `1e-9` 内复现。
- R2 证据：三档最坏归一化增益均为负。tau 0.35 将 FP `126→87`，但 FN `37→56`，卷级两口径各下降 `18.0944`；更高阈值更差。
- 08 证据：tau 0.35 的四种完整包分数均上涨 `+9.0944～+16.0944`，但 FN `96→116`，4/5 个长文件新增 FN或时差分下降；这是数量罚聚合掩盖真实相位损失，不能录取。
- 稳定性：R2、08 full-source 与全部 LOFO 子集都选择 OFF，因此没有 active 双向配置和共同 tau，`development_pass=false`。
- 安全与成本：短文件/300 秒边界/候选子集/确定性均通过，后处理 P95 约 `0.2048 ms`；拒绝原因是选择性不足，不是实现或性能问题。
- 防重复边界：不得扩阈值、改变 60 秒、换 min/max/加权 confidence 或按 08 事后加 veto。只有独立长记录包、显式 event/noise 分支、可解释校准或多台站/走时证据才可重开。
