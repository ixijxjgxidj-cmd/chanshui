检索针对本轮实验暴露的三个具体未知问题：
- **A** 单台 + 未知增益条件下的震级绝对定标（station/site term、relative magnitude）
- **B** 回归任务的测试期自适应与标签漂移校正（TTA、label shift、transductive）
- **C** 仅数秒 P 波的震级估计上限与不确定性（Pd、τc、饱和、概率化）

## 一、问题 A：绝对定标必须有台站项，而台站项每轮都变

| 论文 | 关键结论 | 对本项目的可操作含义 |
|---|---|---|
| MagNet, GRL 2019, 10.1029/2019GL085976 (C299) | 不做归一化以保留幅度；网络可自行学到**距离相关与场地相关函数**；σ≈0.2；明确指出 **station-based learning 能显著提升性能** | 台站项是达到 σ≈0.2 的必要条件。本项目目标域台站匿名且**每轮不同**（R1=`AAA`/`T2`，R2=`XXXX`/`XX`），无法预学台站项 |
| Local Magnitude Scale for Ethiopian Rift, BSSA 2006, 10.1785/0120060051 (C103) | 建立区域 ML 标度必须重新拟合衰减项与**台站校正项** | 广西域的标度未知；跨轮次直接套用会引入系统偏差，与本项目实测一致 |
| Boore 1984, BSSA, 10.1785/BSSA0740051969 (C1179) | 高频傅里叶幅度谱形状由震源谱×路径衰减×场地共同决定 | 谱形状**同时**编码震级与距离 → 单台窄窗下二者不可分离，解释了 R1/R2 谱特征符号翻转 |
| Station Correction to improve EEW magnitude, 2023, 10.1080/13632469.2023.2245498 | 加入台站校正显著改善 EEW 初始峰值震级 | 佐证：没有台站校正时，绝对量级误差不可消除 |

**本项目的实测对应**：H1/H2 的 Richter 型物理式 `M = a·log10(A) + b·log10(R_pred) + c`
在 R1 上截距 c=2.113、在 R2 上 c=3.272，**相差约 1.16 个震级单位**。
即台站增益/场地项跨轮改变，绝对量级不可识别（证据 `outputs/t2_identifiability.json`）。

## 二、问题 C：前几秒 P 波的信息量上限

| 论文 | 关键结论 | 数值 |
|---|---|---|
| Wu & Kanamori, GRL 2006, 10.1029/2006GL026871 (C324) | 前 3 秒 P 波位移幅度 Pd 可定震级 | 需已知增益与距离 |
| Bayesian real-time magnitude, JGR 2008, 10.1029/2007JB005386 (C79) | P 后 2s 位移峰与终震级在 **M4–7.1** 有稳定相关；概率化演进式估计 | 与本项目震级域（4.0–6.1）完全重合 |
| A global approach for EEW magnitude, GRL 2013, 10.1002/2013GL058580 (C101) | 比较 5 种仅 P 波方法：**τp_max 对 M<3 不标度、且大震不如 Pd**；Pd 全球标度最稳健 | 不要用主频类参数；用位移峰 |
| Wu & Kanamori on-site Pd, BSSA 2005, 10.1785/0120040206 | Pd 单台可用于现场预警 | 但同样依赖已知增益 |
| PGD 无饱和标度, GRL 2015, 10.1002/2015GL064278 (C174) | 惯性传感器积分到位移有系统偏移；GPS 无饱和 | 本项目只有 int32 计数、无仪器响应 → 无法可靠积分到物理位移 |
| PGD 饱和, JGR 2018, 10.1029/2018JB017093 (C87) | 短窗对大震必然低估 | 与本项目 A1–A3 实测 M6+ MAE 0.64–1.15 一致 |

**结论**：文献里所有「数秒 P 波定震级」方法都以**已知仪器响应 + 已知震中距**为前提。
本项目两者都缺，所以只能取**排序信息**，绝对量级必须另外提供。

## 四、由文献 + 本轮实测共同确定的下一轮设计

**核心判断**：T2 可分解为两个独立子问题
1. **排序**（哪些事件更大）—— 波形可解，已验证：G 系列在 R1/R2 上 r=+0.25…+0.40 同号为正
2. **量级**（整体标度在哪）—— 波形**不可解**（台站项每轮变），必须由先验或批级自适应提供

因此生产候选采用：
```
prediction = 批级中心 + 斜率 × (集成排序分数 − 该批排序分数中位数)
```
- 批级中心：合并已知轮次（R1+R2 train）的评分最优常数；若未来有更多轮次则并入
- 斜率：在 R1/R2-train 上交叉验证标定（**不使用任何 holdout**）
- 排序分数：7 成员集成，每成员先减自身预测中位数（消除成员偏置）

**实测支撑**（`outputs/t2_loro.json`）：直推式中心化在两个方向都超过合并先验
- R1→R2：126.32 vs 124.86
- R2→R1：103.60 vs 93.57

**被文献与实验共同否决的方案**：
- ❌ 直接回归绝对震级（LORO：R1→R2 仅 73–85 分，远低于 124.86）
- ❌ 跨轮仿射/分位映射标定（六种全败，最好 83.42 vs 124.86）
- ❌ 谱形状特征直接外推（R1→R2 r=−0.493）
- ❌ 主频类参数 τp_max（文献明示不标度）
- ❌ 积分到物理位移（无仪器响应）
