# T2 第 27 轮：可信台站血缘与分层收缩实验

## 合规边界

- 本轮全部训练和数据获取只在远程 `/root/5.6+chanshui1` 进行。
- 公开 STEAD 重新构建专用缓存 `outputs/t2_cache_station27`，逐样本保留真实 `network.station` 血缘；不复用旧的无台站血缘缓存作本轮结论。
- 本轮只读取公开 STEAD；未读取 R1/R2 train、R1/R2 holdout、08-an、08-exam 或其衍生物。

## 血缘修复

旧缓存只保存 `source_id`，同一事件可能对应多个台站，无法可靠回接台站。第 27 轮从公开 STEAD 元数据和波形重新构建 P±5 秒缓存：60,466 条记录、103 个网络、1,754 个台站，X/y/net/sta 数组长度完全一致。构建和形状核验脚本随本轮保存。

## 文献依据

OpenAlex 109 条、Crossref 200 条候选，人工精读 18 篇分层/随机效应/经验贝叶斯/收缩估计论文。核心结论：未知台站的随机效应应收缩到总体均值；逐台站自由参数只能用于已有该台站标签的场景；真实台站 LOSO 是必要选择门槛。完整精读记录见 `literature.md` 和 `memory/round27_literature.md`。

## 实验设计

在真实台站记录数至少 250 的 8 个台站上，每台站构造 320 个公开批（50–200 条）。比较：

- `gbm_global`：全局 GBM v2 基线。
- `gbm_shrunk`：全局 GBM + 经验贝叶斯台站项收缩；未知台站效应收缩为零。
- `gbm_group_centered`：训练台站去中心后拟合的分层模型。
- Huber 与 Ridge 稳健基线。

模型选择只用真实台站 LOSO 的平均 MAE 和最差台站 MAE。

## 结果

| 模型 | LOSO MAE | LOSO r | 最差台站 MAE |
|---|---:|---:|---:|
| 全局 GBM | **0.07502** | **0.9270** | **0.15382** |
| GBM + 收缩 | 0.07502 | 0.9270 | 0.15382 |
| 分组去中心 GBM | 0.12759 | 0.8729 | 0.22313 |
| Huber | 0.09075 | 0.9094 | 0.22474 |
| Ridge | 0.08787 | 0.9145 | 0.22309 |

收缩模型与全局模型完全相同，符合“未见台站随机效应后验均值为总体均值”的理论。分组去中心反而严重退化。

## 判定

没有候选同时优于全局 GBM 的平均 LOSO MAE 且不恶化最差台站 MAE。因此本轮不冻结新候选、不读取比赛 train、不改变当前主中心估计器。第 27 轮验证了：对未知台站，复杂分层项不能凭公开训练台站直接迁移；后续应转向无标签批级域诊断/不确定性回退，而不是继续扫描台站自由效应。
