## 判定：候选被证伪，生产保持 λ=0.40

第34/35轮候选在公开 STEAD 台站 LOSO 上稳定提升（+2.7 至 +3.4 分，五组设置一致），但在两个外部真题 train 划分上**全部退化**：R1 −3.1 至 −3.5 分，R2 −2.0 至 −7.5 分。方向在两个独立包上一致，不是噪声。

**生产继续冻结 λ=0.40，不做任何修改。**

## 机制诊断：公开协议为何失效（本轮的真正价值）

最优收缩尺度为 `λ* = ρ(z,y) · σ_y / σ_z`。本轮实测：

- R1：`σ_y/σ_z = 0.4255/0.3287 = 1.294`；若 `λ*=0.40` 最优，则隐含 `ρ ≈ 0.31`。
- R2：`σ_y/σ_z = 0.3438/0.3898 = 0.882`；若 `λ*=0.40` 最优，则隐含 `ρ ≈ 0.45`。
- 公开 STEAD LOSO 标定：`ρ̂ ≈ 0.638`。

即**公开域把 ρ 高估了约一倍**。原因是结构性的：7 成员教师本身在 STEAD 上训练，其逐记录判别力在 STEAD 内被系统性夸大。台站 LOSO 只留出了台站，**没有留出训练分布**，因此它不能用于标定任何与"逐记录判别力强度"直接相关的参数。

`σ_y` 的估计本身是可用的（R1 估 0.4255 对真 0.4949，R2 估 0.3438 对真 0.3688，方向与量级都对），所以失效点不在分位模型，而在 ρ。

## 由此确立的新协议约束（写入后续所有轮次）

1. 任何依赖 `ρ(z,y)`（即逐记录判别力）的参数，**不得**在与教师训练集同源的公开数据上标定。
2. 这类参数只能在**真正跨域**的公开数据上标定：训练集与验证集必须来自不同区域、不同台网、不同仪器体系。
3. 台站 LOSO 仍然对**批中心**类参数有效（第25/27/33轮结论不受影响），因为中心估计依赖批级统计量而非逐记录判别力。

## 对第31轮 INSTANCE 路线的直接意义

本轮把 INSTANCE 从"更多训练数据"升级为**必需的协议组件**：只有 STEAD 训练 → INSTANCE 验证这样的真实跨域设置，才能测得 ρ 的跨域衰减系数，从而给出可外推的 λ。这为正在进行的完整波形下载提供了明确的、由负结果驱动的用途。
