## 资源边界与判定

INSTANCE 官方下载器明确要求约 310GB 下载空间，解压后约 160GB 单体 HDF5。该结构不能安全按记录分片，且当前网络下载整包会造成无界长任务。因此本轮只完成元数据和资源审计，没有启动波形下载或训练，也不宣称多源模型有提升。

INSTANCE 是下一轮最有价值的数据侧路线，但需要专门的远程大盘/断点下载策略，或使用已拆分的公开镜像；在获得可控分片前，继续保持 STEAD 七成员主线，不用元数据标签调参。

## 追加的 Range/前缀验证

服务器支持 HTTP Range，但 INSTANCE 波形是单体 bzip2 后的 HDF5。远程尝试下载前 1.5GB 并顺序解压 400MB，HDF5 打开失败：文件头记录的 `stored_eof ≈ 167,441,184,816`，证明必须拥有完整 HDF5 才能随机读取。前缀采样方案不可行；临时前缀文件已删除，只保留 236MB 元数据。
