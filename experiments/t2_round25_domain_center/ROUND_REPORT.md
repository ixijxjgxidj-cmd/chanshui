# T2 第 25 轮：公开留域批中心估计与域不变排序

## 合规边界

- 训练与公开验证仅读取远程 STEAD 缓存 `outputs/t2_cache_p10`；本地未做训练或数据下载。
- 伪域由公开 `source_id` 的稳定哈希形成，批标签只来自公开 STEAD 的震级；无比赛数据进入训练、模型选择或超参数选择。
- R1/R2 仅在公开 LODO 结果冻结后，读取各自预注册 train 清单（140 条）作一次外部报告；脚本断言 train/holdout 无交集、输入路径只能是 `r1_t2` / `r2_t2`。
- 本轮不读取 R1/R2 holdout，也不读取 08-an、08-exam 或其任何衍生产物。

## 文献依据

双源检索得到 OpenAlex 98 条与 Crossref 200 条候选，人工精读 18 篇，完整条目和可操作结论在 `literature.md`。关键结论是：CORAL/IRM 适合做小权重不变性约束，但可能抹去标签条件信息；因此将排序与批中心解耦，并保留强 ERM/GBM 基线。无标签目标批只使用成员预测及其分布统计，不能假定目标真值分布。

## 实验设计

- 公开样本：STEAD M3.8–6.5，32,602 条记录。
- 域划分：按公开事件 ID 的稳定哈希分成 4 个伪域；每域生成 800 个可变大小批，共 3,200 批。批大小为 50–200，震级窗随机采样。
- 无标签特征：7 个冻结成员预测的均值、批内中心化排序、成员离散度的 10/25/50/75/90 分位数、标准差及批大小；不输入任一批真震级。
- 候选中心头：Gradient Boosting、ExtraTrees、Huber regression。选择指标为公开四域 leave-one-domain-out 的 MAE，平局再比较相关性。

## 公开留域结果

| 模型 | 留出伪域 MAE | 留出伪域 r | 四域 LODO MAE | 四域 LODO r |
|---|---:|---:|---:|---:|
| GBM | 0.0801 | 0.9811 | 见原始 JSON | 见原始 JSON |
| Huber | 0.0795 | 0.9792 | 见原始 JSON | 见原始 JSON |
| ExtraTrees（冻结） | **0.0754** | **0.9829** | **0.0658** | **0.9816** |

ExtraTrees 按公开 LODO 指标冻结。该结果仅说明公开域的批中心反演可行，不构成对比赛域得分的承诺。

## 冻结后外部 train-only 报告

| R2 train | 140 | 5.20 / 4.983 | −0.217 | 0.308 | 141.31 | 142.37 |

此报告只用于记录冻结候选的跨域行为，不可据此重新选择模型，也不触发重新读取 holdout。相较轮 23 的 GBM（R1 +0.15、R2 −0.16），本候选改善 R1 中心但恶化 R2 中心，且 R2 排序略升。因此它暂不替换当前 v2 GBM 主中心估计器；保留为备选和下一轮的域泛化基线。

## 结论和后续

本轮否定“仅凭公开 LODO 优胜即可全面替换中心头”的假设。下一轮应扩大公开域的真实台站/网络分组，避免 source-id 哈希伪域低估数据漂移，并把中心估计器纳入分层/置信度加权的模型选择框架。所有选择仍只在公开数据完成，R1/R2 仅作冻结后的 train-only 报告。
