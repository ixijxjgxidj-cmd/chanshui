# T2 第38轮：真正跨区域重训与收缩尺度迁移

## 合规

只使用远程公开 STEAD 缓存 `/root/5.6+chanshui1/outputs/t2_cache_station27`，未读取任何比赛数据、R1/R2 或 08 数据；未在本地训练或下载。每个区域组合的模型均在远程重新训练，没有复用已见过全部 STEAD 的冻结教师。

## 为什么重开

第34/35轮只做台站留出，但教师已经在全 STEAD 上训练，台站 LOSO 仍会高估逐记录判别力。第38轮按地理台网互斥做 `训练区域 A → 标定区域 B → 评估区域 C`，事件级隔离，重新训练成员，直接测跨训练分布的 `rho` 衰减。

区域分组：

- ALASKA: AK/AT/AV
- CALIF: CI/BK/AZ/NN
- GREECE: HL/HP/HT/HA
- CHILE: C/C1/PB
- NZ: NZ
- OTHER: TA/OK/GS/PR/SV/IU/MN/CN/KR/GO

## 预注册指标

- `rho_in`：训练区域内事件留出的 corr(z, y)
- `rho_calib`：独立标定区域 B 的 corr(z, y)
- `rho_eval`：独立评估区域 C 的 corr(z, y)
- 用 B 选出的 λ 在 C 上比较生产 λ=0.40
- 官方 T2 逐记录截断评分 `score200`

## 结果

| OTHER→NZ→CHILE | .294 | .364 | .217 | .738 | 158.29 | .45 | .15 | 158.21 |

跨五组组合平均：

- rho 衰减：0.884
- 生产 λ=.40：157.515
- B 标定 λ：158.947（+1.432）
- C oracle：159.020
- 最差台站/组合：153.912 → 156.071

## 判定

跨区域重训证明了两件事：

1. 之前公开台站 LOSO 得出的 λ≈0.8–0.9 确实严重偏大；真正跨训练分布后最优 λ 的均值只有约 0.20，符合 R1/R2 外部报告中高 λ 退化的方向，但本报告不使用比赛数据做论据。
2. 用独立区域 B 标定 λ，再迁移到 C，平均 score200 比生产 λ=.40 高 1.432，最差组合也提高 2.158；这证明“跨域标定”本身可行。

但候选尚未冻结为生产：五组中 OTHER→NZ→CHILE 的 B 标定 λ=.45 在 C 上略低于生产（158.21 < 158.29），且训练区域选择与本届广西域仍不完全匹配。需要 INSTANCE 完整数据建立更多区域组合，才能做最终冻结。

## 约束

- 不把台站 LOSO 的 λ=.8 结论迁移到比赛；
- 不读取 R1/R2 holdout；
- 不在 INSTANCE 到位前修改生产；
- 只有跨区域组合在新独立区域上同时通过平均分和最差组合门槛，才进入下一轮候选。
