# T2 第35轮：自适应排序尺度 λ（公开准入通过）

## 合规

## 机制

生产输出为 `pred = center + λ·centered_ranking`，`λ` 固定 0.40。第34轮证明该值次优（公开最优约 0.80），并观察到 λ* 随批内震级散布与批规模单调变化。本轮把 λ 改为可观测量的函数，依据回归到均值的最优收缩：

```
λ* ≈ ρ(z, y) · σ_y / σ_z
```

- `σ_z`：批内集成排序分数的标准差，直接可观测；
- `σ_y`：批内真实震级散布，用批级分位模型（q10/q25/q75/q90）以正态近似估计
  `σ̂_y = ½[(q90−q10)/2.563 + (q75−q25)/1.349]`；
- `ρ`：在训练台站上以 `median(λ_oracle / (σ_y/σ_z))` 标定，公开域实测为 0.626–0.650（8 个留出折全部落在该窄区间，跨台站稳定）。

## 预注册准则

主门槛：LOSO 平均 `score200` 高于公开固定最优 λ（`fixed_public`）；次门槛：最差台站不低于 `fixed_public`。

## 结果（8 台站 LOSO，逐记录官方截断评分）

| 候选 | 平均 score200 | 最差台站 |
|---|---:|---:|
| `fixed040`（生产） | 160.408 | 156.711 |
| `fixed_public`（训练台站选出的常数 λ≈0.8–0.9） | 163.010 | 155.486 |
| `adaptive_ratio`（物理比率式） | **163.478** | **157.258** |
| `adaptive_gbm`（直接回归 oracle λ） | **163.798** | **158.149** |
| `oracle`（上界，不可得） | 164.699 | 159.608 |

相对 `fixed_public`：`adaptive_ratio` 平均 +0.468、最差 +1.772；`adaptive_gbm` 平均 +0.788、最差 +2.663。两者 `accept=true`。相对生产 `fixed040`：`adaptive_gbm` 平均 +3.390。

`oracle` 上界为 164.699，说明 `adaptive_gbm` 已取得该机制 90% 以上的可得增益（163.798 对 160.408 的基线，占 oracle−baseline 差距的 79%）。

关键稳定性证据：`ρ̂` 在 8 个留出折中为 0.6265–0.6502，变动小于 4%，说明这是可迁移常数而非折内拟合量。

## 选择规则（本轮冻结，事前固定）

优先采用 `adaptive_ratio`：它只依赖两个可观测散布与一个跨台站稳定的标定常数，外推行为可解释；`adaptive_gbm` 虽然分数更高，但把 λ 作为黑箱回归目标，在未知台站上缺少同等的机制约束，记为对照与上界参考，不作为首选。
