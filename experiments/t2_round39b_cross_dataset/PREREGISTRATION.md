# 第 39B 轮：STEAD 与 INSTANCE 的双向跨数据集验证（预注册）

> 状态：前置数据下载与审计中；本文件先于训练编写，用于锁定实验协议。

## 问题

第 39A 轮显示 JEPA 在公开 STEAD 的自然区域留出中优于 CNN 和同架构 scratch。这个结果不能证明它可迁移到完全不同的地震网络、仪器与区域。第 39B 轮的唯一目标是用公开 INSTANCE 的官方 `train` / `dev`，验证该增益是否能跨数据源双向成立。

## 硬性合规约束

- 绝不读取、解压、特征化、评估或依据以下文件及衍生产物改方法：`08-an.zip`、`08-exam.zip`、第 1 轮比赛包、第 2 轮比赛包。
- 唯一允许输入是公开 STEAD 缓存与完整性审计通过的公开 INSTANCE 缓存。
- INSTANCE 官方 `test` 划分在加载器层被拒绝；仅可出现 `train`、`dev`。
- 所有数据读取均由白名单守卫约束；历史比赛衍生物在远程机器上存在时也必须被阻断。
- 每个训练/标定/评估切分按 `source_id` 事件隔离。

## INSTANCE 完整性闸门

必须全部通过才可训练：

1. 下载文件大小精确等于 `161,809,684,189` 字节；
2. `bzip2 -t` CRC 校验成功；
3. 解压进程已退出，HDF5 在连续 3 次采样中大小不变；
4. 400 条随机 metadata 记录均能在 HDF5 `data/<trace_name>` 找到，形状为 `3 × 12,000`、数值全有限；
5. 对记录的 `trace_E/N/Z_min_counts` 与 HDF5 通道 0/1/2 最小值一致，确认通道顺序为 E/N/Z；
6. 构建缓存时只筛选官方 `train` / `dev`、震级 `3.8–6.5`、P±5 s、100 Hz、三分量、事件均匀抽样；任何无效记录导致构建失败而非保留部分缓存。

## 对照臂与固定超参数

四条臂共享相同的 3×1000 输入、增益扰动、监督 epoch、优化器和 `λ` 网格：

| 编号 | 训练/预训练数据 | 模型 |
|---|---|---|
| S-S | STEAD | 同架构 Transformer，从零训练 |
| S-J | STEAD | JEPA-MR（只可预训练在不含评估域的公开 STEAD 训练池） |
| I-S | INSTANCE 官方 train | 同架构 Transformer，从零训练 |
| I-J | INSTANCE 官方 train | JEPA（只可预训练在 INSTANCE train 的事件子集） |

在双数据源混合前，先要求每个源内 JEPA 相对 scratch 的增益跨源成立。仅当下一节的门槛同时通过，才开启混合 STEAD+INSTANCE 和多成员蒸馏实验。

## 双向评估协议

### 方向 A：STEAD → INSTANCE

- 从 STEAD 选择训练事件 A 和独立公开标定事件 B；B 仅选择 `λ`。
- INSTANCE 的官方 dev 仅一次做评估 C；它不进入预训练、监督训练、成员选择或 `λ` 选择。
- 报告平均、最差 STEAD 自然训练域和 INSTANCE dev 的得分、相关性与 `λ`。

### 方向 B：INSTANCE → STEAD

- INSTANCE 官方 train 按事件切成训练 A 与独立标定 B。
- STEAD 使用完整自然区域作为一次性评估 C；该域不得出现在 INSTANCE 臂的预训练或训练池。
- 报告每个 STEAD 自然区域、平均与最差值。

## 录取规则

JEPA 可进入后续混合训练候选，必须同时满足：

1. 在两个方向中相对对应 scratch，`λ` 由 B 选择后的平均分严格升高；
2. 两个方向的最差域分数均不得下降；
3. 不允许借助任意比赛包、INSTANCE test 或 C 上的结果选择模型、停止 epoch、遮蔽率或 `λ`；
4. 公开结果和白名单访问证据可复现。

只在一个方向获益、或只改善平均但恶化最差域，均记录为未录取或不充分证据。
