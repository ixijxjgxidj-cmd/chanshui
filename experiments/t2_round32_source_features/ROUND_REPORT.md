# T2 第32轮：公开 INSTANCE 源参数/噪声定标可行性

## 目标与合规

本轮只使用远程公开 INSTANCE 元数据 `/root/5.6+chanshui1/public_round30/instance_metadata.csv.bz2`，未读取、训练或调参使用 `08-an.zip`、`08-exam.zip`、第1轮或第2轮比赛包，也未读取 R1/R2 holdout。没有本地数据下载或训练。

## 预注册假设

- H1：P 前噪声与 P 后信号的增益不变比值（SNR）可作为绝对幅度的增益不变量，用于源参数校正。
- H2：即使没有震中距，`log(PGV)` 或 `SNR` 能够在 M3.5–6.5 公开混合域中稳定超过常数中心；若公开自然域不成立，不读取比赛 train-only。
- 评估：只做元数据线性探针与台站内相关性；不以任何比赛结果选择特征或阈值。

## 数据与方法

INSTANCE 元数据 1,143,855 条清洗记录：`source_type=earthquake`、震级类型 ML/Mw、有效 PGV、有效 SNR/RMS。公开 M3.5–6.5 子集 53,759 条，按台站网络/台站代码报告台站内相关性。指标为 Pearson r、Spearman rho、线性探针 MAE；常数基线为该子集震级中位数。

## 结果

| 探针 | n | r | rho | MAE |
|---|---:|---:|---:|---:|
| 全部公开数据：SNR → log(PGV) | 1,143,855 | 0.642 | 0.626 | 0.431 |
| 全部公开数据：计数 RMS → log(PGV) | 1,143,855 | 0.332 | 0.289 | 0.571 |
| M3.5–6.5 常数中位数 | 53,759 | — | — | 0.311 |
| M3.5–6.5 SNR → 震级 | 53,759 | 0.220 | 0.174 | 0.316 |
| M3.5–6.5 log(PGV) → 震级 | 53,759 | 0.392 | 0.305 | 0.298 |
| M3.5–6.5 log(PGV)+log(距离) → 震级 | 53,759 | 0.641 | — | 0.246 |
| M3.5–6.5 SNR+log(距离) → 震级 | 53,759 | 0.299 | — | 0.309 |

台站内多数大样本站点的 RMS/PGV 相关性显著，但少数台站（如 IV.APEC）几乎无关，说明仪器/单位血缘是决定性域变量。

## 判定

H1 部分成立（SNR 与 PGV 有公开相关性），H2 在无距离条件下不成立：SNR 不超过常数，log(PGV) 仅略优于常数；真正的收益来自距离项，而竞赛协议没有可靠震中距。因此本轮不冻结、不进入 R1/R2 train-only，不改生产模型。
